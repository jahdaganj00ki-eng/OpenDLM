OpenDLM options

Free, MIT-licensed download manager for Windows. Extension version -.

Integration

Cancel matching downloads in the browser and send them to OpenDLM instead.

Show a small dismissible "Download with OpenDLM" badge over videos on a page.

Hold this key while clicking a link to send it to OpenDLM even when its type is not on the list.

Hold this key while clicking a link to let the browser download it as usual.

File types taken over

One extension per line, without the leading dot. Downloads whose file name ends in one of these extensions are handed to OpenDLM. Everything else stays with the browser. Lines starting with # are treated as comments.

Handled actions

Download with OpenDLM
Right-click media
Download this media with OpenDLM
Right-click the page
Download all links with OpenDLM
Toolbar button
